What this is

A wallet generator is a page that draws a private key and shows you the addresses it produces. That is a small amount of arithmetic, and it does not require a server — which means that any wallet generator asking you to trust one is asking for something it does not need.

This one asks for nothing. Each page here is a single HTML file with the cryptography, the interface, the fonts and the worker threads inside it. Download it, unplug the machine, open the file: it behaves the same, because there was never anything for it to fetch.

What it will not do

It does not check the balance of any wallet it generates. Not now, not behind a setting. Checking a balance means sending an address to somebody's server, which then knows that address and your IP address belong together — a freshly generated wallet whose balance you "just checked" is not a private wallet any more. And a tool that generates keys and checks their balances is not a wallet generator at all; it is a tool for finding other people's money.

This is not a promise, it is a property. The page's Content-Security-Policy contains connect-src 'none', which is the browser refusing every outbound request the page could make — including in the case where the page's own code has turned hostile. Use your wallet or a block explorer for balances. That is what they are for.

Before you generate anything

If a wallet is going to hold real money, use a hardware wallet. That is not modesty. A device that never exposes the key to a general-purpose computer beats every precaution a web page can take, including all of the ones here. This tool is at its best for learning how derivation works, for checking that a phrase produces the addresses you expect, for testing, and for vanity addresses you have thought carefully about.

If you are going to use it anyway: read the risks of vanity addresses before generating one, and how to generate a wallet safely before generating a phrase you intend to fund.
